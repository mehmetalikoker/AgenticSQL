# What's AgenticSQL Project
This project enables users to execute complex queries across all integrated databases and generate customized, detailed reports.
## ✨ Key Features
- Memory-Optimized Infrastructure: Supported by a robust memory architecture to enhance performance.
- Security Constraints: Restricted the use of high-risk commands such as DROP, DELETE, and ALTER to ensure data integrity.
- Multi-Database Management: Support for multiple databases with real-time connectivity and status tracking.
- Streamlit-Powered UI: Features a modern and responsive frontend developed entirely with Streamlit.

## 🛠️ Tech Stack
- Framework: LangChain
- LLMs Model: gpt-5
- Language: Python 3.x
- Trace: Langsmith
- User Interface: Streamlit
- Test Infrastructure: Pytest


## 🖥️ Installation
1) Clone the repository:

```bash
Bash
git clone https://github.com/mehmetalikoker/AgenticSQL.git
```

2) Set up your environment variables in a .env file:
```bash
- OPENAI_API_KEY
- LANGCHAIN_API_KEY
- LANGCHAIN_TRACING_V2 Info
- LANGCHAIN_PROJECT Info
```


## 🖥️ How It Works
Running the class via terminal is sufficient.

 ```bash
For the UI version
- Terminal -> streamlit run agenticsql.py
 ```
